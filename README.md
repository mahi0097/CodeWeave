Women Safety Web App

A web-based application designed to ensure women’s safety by providing live location tracking, SOS alerts, safe/unsafe zone detection using AI, and instant emergency notifications. The app empowers users to quickly alert trusted contacts in case of emergency and view safe routes.

🚀 Features

🌍 Live Location Tracking – Displays current location using maps (Leaflet.js).

🔔 SOS Alerts – Send instant alerts to emergency contacts.

🛡 Safe/Unsafe Zone Detection – AI model trained on datasets of safe/dangerous locations.

📍 Route Suggestions – Shows safe routes instead of risky paths.

📱 User-Friendly Interface – Clean, responsive design for mobile and desktop.

🛠 Tech Stack

Frontend: React.js, TailwindCSS

Maps & Location: Leaflet.js, OpenStreetMap API

Backend: Node.js / Express (for APIs & database)

Database: MongoDB / Firebase

AI/ML Model (Optional): Python (Flask/FastAPI) for zone classification

📦 Installation

Clone the repository

git clone https://github.com/your-username/women-safety-webapp.git
cd women-safety-webapp


Install dependencies

npm install


Start development server

npm start


Run backend server

node server.js
